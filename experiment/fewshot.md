### IPCGRL (Fewshot)

---

**Train Encoder**
```bash
wandb sweep --project encoder_ipcgrl_fewshot --entity <wandb-entity> ../sweep/wandb_sweep/ipcgrl/fewshot/train_encoder.yaml
```

**Train PCGRL**
```bash
wandb sweep --project train_ipcgrl_fewshot --entity <wandb-entity> ../sweep/wandb_sweep/ipcgrl/fewshot/train_pcgrl.yaml
```

**Eval PCGRL**
```bash
wandb sweep --project eval_ipcgrl_fewshot --entity <wandb-entity> ../sweep/wandb_sweep/ipcgrl/fewshot/eval_pcgrl.yaml
```
